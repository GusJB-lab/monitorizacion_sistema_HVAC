# monitorizacion_sistema_HVAC
Control estadístico de procesos aplicados a un sistema HVAC de una tienda textil situada en Panamá (clima tropical), lo que implica refrigeración continua durante todo el año. Los datos analizados provienen de Flores et al. (2020), un estudio que documenta el funcionamiento de la instalación e identifica eventos de fallo en sensores mediante SEM.
